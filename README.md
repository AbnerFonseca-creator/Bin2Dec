# Bin2Dec Converter 🔢

Um conversor algorítmico desenvolvido em C++ com o objetivo de traduzir cadeias de números binários (base 2) para o sistema decimal (base 10) diretamente via terminal. 

Este projeto foi construído para aprimorar os fundamentos de manipulação de strings, controle de fluxo e alocação matemática de memória na linguagem C++.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** C++
* **Ambiente:** Terminal/Console

## ✨ Funcionalidades
* **Conversão Direta:** Transforma sequências binárias em valores decimais instantaneamente.
* **Validação de Entrada:** O algoritmo garante que apenas os dígitos `0` e `1` sejam processados, emitindo alertas para caracteres inválidos.
* **Execução Leve:** Código otimizado para rodar diretamente na linha de comando com baixo consumo de recursos.
